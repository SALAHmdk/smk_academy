- Points d'attention pour la relecture :
  - Les messages de tsc dépendent de la version. Le tsc du PATH est la version 7.0.2, qui trie par ordre alphabétique les membres d'une union dans ses messages : `'"avance" | "debutant" | "intermediaire"'`. TypeScript 6.0.3 les garde dans l'ordre de déclaration. Les deux messages concernés (M1-L3, M4-L1) suivent tsc 7, et la leçon M1-L3 signale que l'ordre peut différer. Si le contrôle est relancé avec tsc 6, ces deux blocs échoueront.
  - Affirmations vérifiées localement sur tsc 6.0.3 et 7.0.2 : `strict` est activé par défaut, d'où la phrase prudente « les versions récentes activent strict par défaut », avec le conseil de l'écrire quand même. Sur Node 22.23, `node fichier.ts` efface les types et refuse les `enum`. `erasableSyntaxOnly` signale les `enum` et les propriétés de paramètres. Pour éviter toute erreur sur l'évolution des versions, la leçon ne mentionne ni options retirées précises ni numéros de version.
